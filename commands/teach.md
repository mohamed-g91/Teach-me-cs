The user is asking for a teaching note on demand. The session note cap does not apply
here — they asked, so answer.

Read `skills/teach-me-cs/references/writing-notes.md` if you have not already this
session.

Interpret `$ARGUMENTS`:

**Empty** — Teach the most valuable concept from what has actually happened so far in
this session, at the current level. If genuinely nothing has happened yet, say so in one
line and offer nothing further.

**"deeper" / "more" / "again"** — Re-explain the most recent concept one level deeper
than the current dial. This does not change the dial; it is a one-off.

**A topic they name** — Explain it at the current level. Prefer grounding it in something
from this session; if it has not come up, say so briefly and explain it anyway.

**"something new" / "surprise me"** — Pick a concept from
`skills/teach-me-cs/references/curriculum.md` that this session has *not* touched,
favoring one that is a prerequisite for things they do often. Say plainly that it has not
come up yet, since the usual promise is that notes attach to real events.

Use the three-beat format and the current level's depth. One note unless they ask for
more.
